# Подготовка редакций

## Выполнено

1. Общая кодовая база и независимые сборки Free/Pro; один фиолетовый вариант в Free, 32 в Pro. Платные модели исключены из Free JAR, sources JAR и публичного архива.
2. Крылья: сортировка ключевых кадров, интерполяция через границу цикла и кратчайшие углы, плавное смешивание движения и полёта. Предпросмотр использует отдельное состояние игрока.
3. Watermark Free без Free, меняющийся фиолетовый цвет короны. Иконки из «Работа с GUI» сохранены без перерисовки.
4. Вид рук: числовые координаты, Shift с кликом, сохранение при закрытии чата и отключении.
5. Hitbox использует фактические ванильные границы, линии глаз, направление взгляда и отдельные части дракона.
6. Подсветка блоков использует компоненты VoxelShape и смещение глубины без расширения геометрии. Космос и Бездна используют ванильные материалы портала.
7. Серверные пресеты предметов и их классы удалены. Свои предметы задаются по registry ID.
8. Для мобов Target HUD показывает их модель вместо знака вопроса. Интерфейс предпросмотра использует общий материал панелей.

## Границы проверки

Автоматические проверки отдельно запускают Free и Pro в Minecraft 1.21.11: регистрация модулей, ограничения редакции, интерполяция цикла, пользовательские предметы, матрица рук, загрузка всех доступных крыльев, предпросмотр, голем и девять сочетаний формы блока и оформления. Снимки находятся в `build/run/product-<edition>-product/screenshots/`.

Перед выпуском нужна игровая приёмка на целевой сборке с её Sodium/Iris и resource pack: полёт и бег со всеми крыльями, Shift-перетаскивание обеих ориентаций основной руки, реальные музыкальные приложения, размытие на разных разрешениях. Тестовый офлайн-профиль может выдавать ошибки авторизации Realms; они не являются проверкой сетевых аккаунтов.

Публичный репозиторий не создан. Необходимо подтвердить происхождение исторически импортированного кода и моделей согласно THIRD-PARTY-NOTICES. Общая кодовая база открывается, приватные модели сохраняются отдельным пакетом.
