## Что исправлено

### Слова песни

Причина мерцания была в жизненном цикле текста: ходьба/спринт помечали обычную строку как быстрый след, который удалялся на следующем обновлении. Строка создавалась заново с другой позицией и началом анимации. Отдельно ограничение по реальному времени пересоздавало долгие строки и строки на паузе.

Обычная строка теперь сохраняет один объект до смены строки. Режим «Перед игроком · 3D» использует положение камеры при отрисовке, поэтому не отстаёт на один игровой тик. Завершённая строка плавно уходит за 220 мс; одновременно остаются максимум две строки. Пауза сохраняет текст и останавливает его музыкальные часы. Смена песни очищает старые слова.

Добавлены варианты «Плавный подъём», «Караоке», «Без движения». Буквы появляются с короткой последовательной задержкой и подъёмом; завершив появление, строка остаётся неподвижной. Подсветка использует музыкальную позицию, включая паузу и перемотку.

Парсер LRC сохраняет интервал строки до следующей временной метки, учитывает offset, повторные метки и расширенные метки отдельных слов. Убрано сокращение интервалов по предположительной скорости чтения. Раскладка и границы букв кешируются; длинные слова переносятся без разрыва Unicode-символов.

### Источники текста

Пустой результат загрузки больше не кешируется навсегда. Добавлен запас времени для завершения фоновых источников. Повторы одного провайдера не считаются независимым подтверждением. Исправлена оценка перепутанных полей названия и исполнителя; записи с известной существенно другой длительностью не принимаются за точную синхронизацию.

Для пользовательской песни «8 миля» — madk1d, VILLIAN проверенный поиск LRCLIB содержит строки с временными метками, но без меток отдельных слов. Найдена запись на 115 секунд с перепутанными названием и исполнителем, а также записи другой длительности. Содержимое текста песни в отчёт не копируется. Источник: https://lrclib.net/api/search?q=madk1d%208%20%D0%BC%D0%B8%D0%BB%D1%8F

Точное выделение каждого слова возможно при наличии меток слов. Для обычного построчного LRC движение подсветки между буквами остаётся оценочным. Новый парсер сам по себе не создаёт отсутствующие точные метки.

### Музыкальное состояние

Краткая потеря Windows-сессии больше не скрывает карточку немедленно. Java сохраняет последние данные на 1,5 секунды, замораживая позицию; длительная потеря источника всё же убирает устаревшие данные. Нативный мост удерживает выбранную сессию и сглаживает положение между опросами с учётом скорости воспроизведения.

Пауза не двигает позицию. Большая перемотка применяется непосредственно, небольшое дрожание временных меток корректируется постепенно. Устаревшая загрузка обложки не заменяет обложку новой песни. Расширено распознавание браузеров. Фильтры Auto / Яндекс / VK / Spotify / Браузер сохранены.

### Карточки

Стеклянная карточка получила мягкие границы, отражение и более спокойное свечение. Квадратная — компактное скругление и боковой акцент. Длинные названия сокращаются по фактической ширине шрифта. Карточка и её кнопки остаются внутри экрана, включая старую сохранённую позицию.

Основной индикатор содержит 12 полос с плавной атакой, затуханием и пиками. При паузе полосы успокаиваются. Это декоративная анимация; звуковой спектр не захватывается. Карточка доступна на паузе, перемотка отправляется один раз при отпускании ползунка.
