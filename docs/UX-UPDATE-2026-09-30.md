## Изменения

1. **Музыка:** убран второй параллельный путь play/pause через запуск отдельного media-control скрипта. Кнопка отправляет один HTTP control запрос. Исправлен сброс порта при старте NowPlayingClient. Кнопки музыки используют выбранную тему звуков и общую громкость. Стиль «Минимализм» убран из выбора и отрисовки музыкальной карточки и всплывающих уведомлений. Квадратная карточка получила небольшое скругление и спокойную границу. Уведомление о треке разносится с музыкальным HUD при пересечении. Семь полос с плавной атакой/затуханием; это декоративная анимация, не измерение звукового спектра.
2. **Слова песни:** подключён используемый renderer/manager; три режима, по умолчанию «Перед игроком · 3D». Исправлены обратная сторона текста и перекрытие фоном в режиме блока. Размер, расстояние и разлёт управляются настройками. Уменьшено количество повторных отрисовок текста. Неудачная загрузка lyrics повторяется с паузой.
3. **Темы:** сохраняются blur, glow, refraction, edge strength, угол градиента, движение цвета и прозрачность палитры; копирование не теряет материал. Dirty определяется фактическими изменениями. Ошибка сохранения сохраняет открытый редактор и показывает «Ошибка · повторить». Неподвижное удержание ползунка не пересоздаёт тему каждый кадр. Исправлен звук `click` и размер кнопки создания темы.
4. **Текст и навигация:** длинные варианты используют dropdown, подписи и кнопки ограничены своей шириной. Заголовки настроек стали простыми строками с акцентом вместо декоративных капсул с неподдерживаемыми глифами. Переработан раздел «О проекте». Поиск не пересчитывает ширины всех префиксов строки и использует небольшое появление без масштабирования шрифта. По последнему указанию пользователя в шапке, About и ватермарке используется исходный `nv:textures/logo.png`.
5. **Звуки:** набор «NV · Стекло», 11 коротких событий интерфейса; тихие оригинальные синтезаторные тоны смешаны с Kenney Interface Sounds (CC0). «NV · Тактический» использует короткий Kenney Impact Sounds (CC0), не извлечённый PUBG звук. Лицензии включены в JAR. Старый конфиг сохраняет свой ранее выбранный набор; новый набор доступен в настройках. Громкость 0 действительно отключает звук.
6. **Питомцы:** добавлен отдельный постоянно фиолетовый «Маскот NV». Избегание владельца обновляет цель полёта без мгновенного переноса позиции; добавлен гистерезис догоняния. Фантазийные варианты сохранены. Маскот не используется как логотип клиента.
7. **Корона и эффекты:** китайская шляпа заменена восемью кристаллами; около 256 вершин вместо прежней плотной сетки. По умолчанию корона и круг прыжка используют цвета темы, существующие пользовательские настройки сохраняются. В круге убраны жёстко заданные голубые/розовые цвета клиентского режима.
8. **Анимации:** открытие инвентаря — короткий плавный выезд без сильного overshoot. Уведомления — боковое появление с постоянным размером текста. Закрытие инвентаря отдельной новой анимацией пока не реализовано.

## Доработка 30 сентября: музыкальные источники и стабильность UI

- Сохранены текущая композиция GUI и исходный логотип NV: отклонённые референсы не внедрены.
- Старый закрытый Windows helper заменён собственным `NvMediaHelper.exe` (23 040 байт), исходники и воспроизводимая сборка в `tools/media-helper/`. Удалены неиспользуемые Windows helper, VolumeControl и Python controller. В новый продукт не входит второй путь toggle через Python/медиаклавишу.

Выбор устойчив при перестановке сессий и защищён на три секунды после команды. Настройка отправляется при изменении источника/порта, с повтором после ошибки, а не на каждом тике.

Windows SMTC сообщает идентификатор приложения, а не URL вкладки; гарантировать точное различение Яндекса и VK внутри одного браузера нельзя. Основание: [Windows SMTC API](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssession?view=winrt-26100), [Media Session API](https://web.dev/articles/media-session).
