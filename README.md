# Nivorat Visual

Клиент для Minecraft 1.21.11, Fabric и Java 21. Общий исходный код используется в двух редакциях.

| Редакция | Косметические крылья | Интерфейс |
| --- | --- | --- |
| NivoratFreeVisual | Один фиолетовый вариант | Мозаика, закреплённый watermark без надписи Free |
| NivoratVisual | 32 варианта | Выбор материала, перемещение HUD, предпросмотр крыльев слева |

## Сборка

Установите JDK 21 и выполните `./gradlew assemble -PnvEdition=free --no-daemon`.
На Windows можно использовать `powershell -File tools/build_editions.ps1 -JavaHome "путь к JDK 21"` для обеих редакций.

Готовые файлы находятся в `build/libs/`. Обе редакции имеют один mod ID `nv`: устанавливайте только один продукт за раз. Fabric API необходим.

Публичный архив содержит общий код и одну модель `crystal`. Для сборки полной редакции распакуйте приватный архив косметики в корень проекта и выполните сборку с `-PnvEdition=pro`. В приватном архиве находятся остальные 31 модель и их текстуры. Переключатель редакции задаётся при сборке, не в игровом конфиге.

## Управление

* Вид рук: включите модуль, откройте чат и удерживайте Shift с левой кнопкой мыши на основной руке. Двойной клик выбирает любую руку; колесо меняет размер. Доступны числовые настройки и сброс.
* Подсветка блоков: варианты Контур, Космос и Бездна следуют форме блока при разрушении; ванильные трещины сохраняются.
* Подсветка предметов: ванильные переключатели и поле «Свои предметы» с ID через запятую, например `minecraft:diamond,minecraft:emerald`.
* Hitbox: настройте контур, заливку, толщину, уровень глаз и направление взгляда. Настройки меняют отображение, физическая геометрия остаётся ванильной.
* Полная редакция: откройте настройки крыльев для вращающегося предпросмотра слева.

## Проверки

`./gradlew runProductionClientGameTest -PnvEdition=free -PnvTestSuite=product --no-daemon`

Повторите с `-PnvEdition=pro`, имея полный пакет моделей. Тесты работают в отдельном мире `build/run/` и не входят в продукт. `python tools/verify_jar.py build/libs/NivoratFreeVisual-1.0.1.jar` проверяет состав JAR. `python tools/package_product.py` создаёт архивы исходников и приватной косметики.
